Privacy Policy

Last updated: October 11, 2026

shorts-uploader ("the app") is a personal tool used only by its owner to manage the owner's own YouTube channel.

What data the app accesses

  • With the owner's authorization, the app uses the YouTube Data API to upload videos to the owner's channel (youtube.upload) and to read the channel's statistics such as views, likes, comments and subscriber count (youtube.readonly).
  • The app does not access any data of other Google users.

How data is stored and used

  • The authorization token is stored as an encrypted secret in the owner's private GitHub repository and is used only to perform the actions above.
  • Channel statistics are saved in the owner's private repository to decide which videos to make next.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account → Third-party connections.
